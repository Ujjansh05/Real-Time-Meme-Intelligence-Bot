# Third-party notices

Humour Hub's source code is licensed under MIT. AI models and source platforms have their own terms.

- [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/) hosts optional AI inference. The selected models are [Qwen3](https://developers.cloudflare.com/workers-ai/models/) for text and [Llama 3.2 Vision](https://developers.cloudflare.com/workers-ai/models/llama-3.2-11b-vision-instruct/) for image understanding. The deployer must review and accept the models' licenses and acceptable use terms before enabling them. In particular, Cloudflare requires a license acceptance request for Llama 3.2 Vision.
- [Ollama](https://docs.ollama.com/) can run optional AI inference on the API operator's own computer. The suggested [Qwen2.5-VL 3B](https://ollama.com/library/qwen2.5vl:3b) model accepts text and images and is listed under Apache 2.0. Model weights are downloaded separately by the operator and are not bundled with this extension.
- [Wikimedia Analytics API](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/reference/page-views.html) supplies Wikipedia readership counts. Trend cards attribute Wikipedia and link to articles.
- [Reddit Data API](https://support.reddithelp.com/hc/en-us/articles/42728983564564-Responsible-Builder-Policy) is optional and must be enabled only after approved access.
- [Bluesky AT Protocol](https://docs.bsky.app/) is optional. Trend cards attribute Bluesky and link to posts.

User supplied meme images remain the responsibility of the person uploading them. Distribute only templates that are original or permitted for redistribution.
